# Universal knowledge (layer 2)

Reusable, company-neutral methodology that ships with TTROS: how to define an ICP, structure an offer, write a
LinkedIn post, qualify a lead. It is read through the existing Context Assembler **together with** the company's
own Business Brain, and it works when that Brain is empty.

- One method per folder: `universal/<domain>/<method-id>/METHOD.md` (front matter: `id`, `title`, `version`, `domain`, `summary`, `keywords`).
- Every method is registered in `manifest.json` with authorship, licence and a redistribution decision. New files
  are `pending` until a human clears them; unregistered or `pending` material is never exported.
- Never put company facts here: no names, prices, offers, results, voice samples or client details. Those belong in the
  company's Business Brain (layer 3). A method describes *how*; the Brain supplies *who and what*.
- Applied, company-specific variants live under `company/` (never shared). Material awaiting a rights decision goes under `universal/_pending/` (private).
- Domains are added as the private installation develops them; this folder is not a finished library.

See `context/LAYERS.md`.
